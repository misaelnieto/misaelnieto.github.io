## Táctica: Self-Contained Answer Blocks & Citation Capsules

**Descripción:** Creación de fragmentos de contenido (bloques) diseñados para ser autónomos, concisos y directamente citable por motores de IA y LLMs. Son la unidad fundamental para obtener "Answer Engine Optimization" (AEO).

**Popularidad:** Muy alta (tendencia clave 2025-2026).

**Relevancia:** Fundamental para la visibilidad en búsquedas de IA, resúmenes instantáneos (como "Answer Summaries" de CNN) y fragmentos de respuesta directa.

**Características Clave:**

*   **Autonomía:** Cada bloque debe poder entenderse y responder una pregunta específica sin necesidad de contexto externo inmediato.
*   **Longitud:** Generalmente entre 120 y 180 palabras por bloque (referencia: 134-167 palabras para "citation capsules").
*   **Claridad y Concisión:** Lenguaje directo, enfocado en el dato o la respuesta.
*   **Densidad de Información:** Priorizar hechos, estadísticas y datos originales.
*   **Formato:** Estructura clara, fácil de parsear por IAs.

**Implementación:**

*   Identificar preguntas clave que el contenido responde.
*   Crear bloques dedicados para cada pregunta/respuesta.
*   Utilizar encabezados claros o marcadores de lista para delimitar los bloques.
*   Asegurar que cada bloque incluya enlaces a entidades relevantes si es apropiado.

**Ejemplo de Prompt:**
"Create 3 self-contained answer blocks (around 150 words each) for the topic 'AI SEO Trends 2026'. Ensure each block can be cited by Perplexity and answers a specific question about the topic."

**Fuentes:** claude-blog, claude-seo-ai, claude-seo, seo-geo-optimizer.
