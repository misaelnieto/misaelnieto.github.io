Demos y Herramientas

“Demos, herramientas y proyectos archivados — aplicaciones web interactivas, experimentos con Django y React, plugins para LFS y paquetes de sintaxis, todo open source.”

Lo que he construido

Una muestra de lo que he publicado a lo largo de los años — aplicaciones en vivo que puedes probar, librerías y plugins que puedes reutilizar, y un cementerio de lo que ya fue retirado. Todo es open source salvo que el repositorio indique lo contrario.

Demos

Aplicaciones en vivo, widgets interactivos y prototipos. Si tiene una URL publicada, haz clic y pruébala.

  • LM317 Calculator — disponible en lm317-calculator.vercel.app. Calculadora en React para el regulador de voltaje ajustable LM317: elige tus resistencias y obtén el voltaje de salida.
  • CHPT Konvertilo — disponible en noenieto.com/demos/chpt-konvertilo. Convierte subtítulos CHPT (generados por algunas herramientas de autoría de DVD) a XML de Matroska o etiquetas de Audacity.
  • Limpia Emails — pega un bloque de texto y extrae todas las direcciones de correo que contenga, sin duplicados.
  • Mallonga — disponible en eta.noenieto.com. Un acortador de URLs clásico construido con Django, con desarrollo guiado por pruebas.
  • Intro IA Creativa — Equipo 3 — disponible en intro-ia-creativa-equipo-3.vercel.app. Proyecto final en equipo para un curso de IA creativa.
  • Amalita Ahorro — chatbot en español que da consejos de finanzas personales y ahorro.
  • Deseos — app Android para lista de deseos de boda, escrita en Kotlin.
  • DjangoAPIREST-Demo — tutorial mínimo de una API REST con Django, en español.

Herramientas

Librerías, plugins, paquetes de sintaxis y pequeñas utilidades que he publicado.

  • vercel-storage — wrapper en Python para la API de almacenamiento de Vercel.
  • Ajedrez — librería de ajedrez ingenua en Rust. Por ahora, un proyecto de aprendizaje.
  • Programación de Interfaces Gráficas con GTK 4 y C — libro gratuito (en español) sobre programación de interfaces gráficas con GTK 4 y C. Léelo en Read the Docs.
  • Mezquite — herramienta exploratoria para administradores de bases de datos en Linux, en C.
  • Algoritmos-1 — mis soluciones a la primera parte del curso de algoritmos de Coursera.

Archivados

Repositorios de solo lectura conservados para la posteridad.

  • itm_2025_fis — repositorio de prácticas para mi grupo de Fundamentos de Ingeniería de Software 2025. También enlazado desde Como docente. Archivado el 4 de febrero de 2026.
  • resume_rst — mi currículum escrito en reStructuredText, compilado a PDF con rst2pdf. Reemplazado por Como profesional.
  • Webpage to PDF — GitHub Action — GitHub Action reutilizable que carga un sitio web y lo renderiza a PDF.
  • jekyll-pdf-thumbnail — plugin de Jekyll que genera miniaturas para archivos PDF. Publicado como RubyGem.
  • Tracey — herramienta para visualizar e inspeccionar archivos de datos de DEVSIM.
  • DEVSIM GSoC 2018 — simulación experimental de celdas solares en DEVSIM, de mi Google Summer of Code 2018.
  • sublime-silvaco-tcad — resaltado de sintaxis para Sublime Text para archivos de entrada de Silvaco TCAD.
  • in.vim — sintaxis de Vim para decks de entrada de Silvaco Atlas y Athena.
  • Hookdeploy — despliega repositorios de Bitbucket al hacer git push, en PHP.
  • LFS shipping — Zone / Zip / Weight — método de envío para LFS basado en zona, código postal y peso.
  • LFS shipping — UPS — método de envío UPS para Django-LFS.
  • LFS Conekta — procesador de pagos Conekta para LFS.
  • LFS Compropago — procesador de pagos Compropago para LFS.
  • LFS Foundation theme — tema responsivo para LFS basado en Zurb Foundation.
  • LFS Ipsum — genera contenido de prueba para una instalación de LFS.
  • Haroopad FlatPak — manifiesto Flatpak para el editor Markdown Haroopad.
  • Spionisto NG — prototipo de sistema de videovigilancia con cámaras IP, en Python y GStreamer.
  • Flipbuq — convierte el flujo de tu webcam en un flip book imprimible.
  • json_eav_example — pequeña aplicación web que demuestra el patrón Entity-Attribute-Value con una API JSON.
  • Calculadora Gasolinazo — app Android que comparaba precios de gasolina en México y EE. UU. lado a lado.
  • Fotiloj — (fotiloj, en esperanto «cámaras».) Pequeña aplicación fotográfica en JavaScript, antes disponible en fotiloj.vercel.app.
  • YetAnotherTodoApp — una app de TODOs en CodeIgniter (PHP), porque todo desarrollador termina escribiendo una.
