Script para automatizar la creación de archivos .metadata

Script simple en Python para automatizar la creación de archivos .metadata en directorios de skins de temas de Plone.

Aviso — entrada histórica

Este post se publicó hace más de una década y la tecnología que describe quedó obsoleta. Lo conservo como bitácora: el patrón .metadata en /skins es de Plone 3/4; Plone 5+ usa otro mecanismo de temas.

2009-10-27 1 min read Noe Nieto
python plone scripting automatizacion

Este es un script para automatizar la creación de archivos .metadata que se usan en el subdirectorio /skins de los temas de Plone:

import os

archivos = os.listdir('.')
metadata = '[default]\ntitle=\ncache=HTTPCache\n'

for a in archivos:
    with open(a + '.metadata', 'w') as f:
        f.write(metadata)

Lo puedes ejecutar en el prompt de Python sin problemas. Ya solo falta editar el campo Title en cada archivo.
