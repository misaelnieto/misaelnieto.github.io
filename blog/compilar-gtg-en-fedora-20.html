Cómo correr GTG git en Fedora 20

Pasos para compilar y ejecutar GTG desde el repositorio Git en Fedora 20 usando virtualenv con acceso a los site-packages globales.

Aviso — entrada histórica

Este post se publicó hace más de una década y la tecnología que describe quedó obsoleta. Lo conservo como bitácora: Fedora 20 llegó a fin de vida en 2015; las dependencias de GTG modernas son muy distintas (Python 3.11+, meson, GTK4) y python-cheetah está deprecado..

Me gusta GTG, pero quiero echarlo a andar en Fedora 20 desde el repo Git. Así es como le hice.

Instala estas dependencias:

sudo yum install python-cheetah python-markdown python3-nose python3-pyxdg pygobject3 yelp

Haz un virtualenv, con python3 y acceso a global site-packages:

mkvirtualenv --python=/usr/bin/python3 --system-site-packages gtg

Entra al entorno de virtualenv

Si acabas de lanzar el comando anterior entonces no necesitas hacer nada. El prompt se debería ver algo así:

(gtg)nnieto@wks-nnieto gtg$

Pero hay veces que quieres correr otro comando en la consola con el mismo virtualenv o quieres resumir una sesión de trabajo con GTG. Entonces usarás el comando workon. Ve el ejemplo.

nnieto@wks-nnieto ~$ workon gtg
(gtg)nnieto@wks-nnieto ~$

Instalar liblarch en el virtualenv

Esta librería es una dependencia muy importante. Por fortuna fue fácil echarla a andar. Primero clona el repo de github:

git clone git@github.com:getting-things-gnome/liblarch.git

Luego instala la librería con setuptools:

cd liblarch
python setup.py install

Finalmente hay que clonar gtg, instalar y ejecutar.

Así clonas:

git clone git@github.com:getting-things-gnome/gtg.git

Así instalas:

python setup.py install

Así lanzas gtg:

gtg
