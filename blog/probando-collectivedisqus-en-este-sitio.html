Probando collective.disqus en este sitio

Prueba del plugin collective.disqus para mejoras al sistema de comentarios en Plone, ventajas y desventajas observadas.

Aviso — entrada histórica

Este post se publicó hace más de una década y la tecnología que describe quedó obsoleta. Lo conservo como bitácora: collective.disqus depende de Plone 4; en Plone 5+ el sistema de comentarios cambió.

2009-09-15 1 min read Noe Nieto
plone disqus comentarios add-on

Le instalé collective.disqus a este sitio web. Parece una de las mejores soluciones con respecto al precario sistema de comentarios de Plone, que está muy bien para una intranet o una página corporativa o de una comunidad, pero para un blog se queda corto.

El sistema de comentarios se ve "bien", pero tengo algunas dudas y cosas que cambiaré después…

Primero, se quedó el botón "Agregar un comentario". ¿Cómo se lo quitas? No me gustó cómo quedó.

Después está todo en inglés. Está un poco confuso: ¿qué pasa con usuarios no técnicos?

La interfaz para los usuarios anónimos es mucho más confusa. Otra cosa que no me gustó.

Erik me comenta acerca de otra alternativa:

  • Modificar el workflow para permitir comentarios anónimos.
  • Incluir un producto para usar captchas.

Ya veremos qué más podemos hacer.
